Descripción: Ejercicio realizado en el marco de la Tecnicatura en Análisis de Sistemas. Simula un ticket de compra que solicita los datos del cliente y de dos productos, calculando el total final con IVA incluido mediante el uso de una función. Objetivo: Aplicar el concepto de funciones en Python, integrándolo con el uso de variables e inputs para resolver un caso práctico: el cálculo de un ticket de compra.
Aprendizajes:Una función permite encapsular una operación (en este caso, el cálculo del IVA) para reutilizarla las veces que sea necesario, evitando repetir código.La sentencia return es la que permite que una función "devuelva" un resultado, para poder utilizarlo luego fuera de la función. Es necesario prestar atención al tipo de dato ingresado por el usuario (input() devuelve texto por defecto), utilizando int() o float() según corresponda para poder operar matemáticamente con esos valores.Combinar múltiples variables dentro de un mismo print() permite armar una salida más completa y ordenada, como en este caso, un ticket de compra.
